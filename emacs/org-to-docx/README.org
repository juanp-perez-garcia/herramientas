* Org To Docx

Este proyecto permite exportar documentos `.org` a `.docx` utilizando una plantilla de referencia.

* Flujo de Trabajo (Workflow)

** Opción 0: Usando Docker (Bien no como la IA XD)
1. basta con ejecutar `docker-compose run org-to-docx` y el script interactivo
   se encargará de todo el flujo automáticamente.
   #+begin_src shell
docker-compose run org-to-docx
   #+end_src
** Opción A: Usando Docker (Recomendado)

Para entornos estandarizados, utiliza Docker.

1. Coloca tus archivos `.md` en la carpeta =01-markdown/=.
2. Ejecuta la conversión de Markdown a Org:
   #+begin_src shell
   docker-compose run org-to-docx ./scripts/md-to-org.sh
   #+end_src
   Esto generará los archivos `.org` en =02-org_mode/=, utilizando =templates/setup-file.org= como base.

3. Personaliza el archivo `.org` en =02-org_mode/=. Puedes editar la propiedad =#+DOCX_TEMPLATE:= si necesitas una plantilla distinta a la predeterminada.

4. Ejecuta la exportación a Docx:
   #+begin_src shell
   docker-compose run org-to-docx emacs --batch -l elisp/batch-export.el ./02-org_mode/documento.org auto ./03-docx/documento.docx
   #+end_src
   *Nota:* El parámetro "auto" hará que el script busque la propiedad =#+DOCX_TEMPLATE:= dentro del archivo automáticamente.
** Opción B: Uso Manual en Linux

1. **Dependencias:** Instala `pandoc`, `emacs-nox` y prepara el entorno virtual Python:
   #+begin_src shell
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   #+end_src

2. **Convertir MD a Org:**
   #+begin_src shell
   ./scripts/md-to-org.sh
   #+end_src

3. **Exportar a Docx (Emacs):** Abre el archivo `.org` en Emacs y utiliza =org-export-dispatch= (=C-c C-e=), seleccionando "Exportar a DOCX vía Plantilla". La plantilla se detectará automáticamente a partir de la propiedad =#+DOCX_TEMPLATE:=.

* Detalles Técnicos

- **Paquete de emacs-lisp:** Contiene la lógica para la exportación y la integración con el sistema de exportación de Org-mode.
- **Script de python:** Se encarga de procesar la plantilla DOCX, rellenar los marcadores de posición y generar el documento final utilizando Pandoc.
  - El script necesita =#+INSERT_CONTENT_HERE: {{ INSERT_CONTENT_HERE }}= en la plantilla para insertar el contenido del documento org correctamente.
  - El primer paso rellena la plantilla con los metadatos (ej. =#+AUTHOR:=, =#+TIPO_DOCUMENTO:=).
  - El segundo paso genera el documento `.docx` y reemplaza el marcador ={{ INSERT_CONTENT_HERE }}= con el contenido exportado.
